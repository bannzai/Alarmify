# Plan ファイルチェックリスト

Plan mode でプランファイルを作成する際、以下の該当セクションを末尾に `- [ ]` 形式で追記する。

## チェックリスト

### 実装内容
- [ ] 変更対象ファイルごとに具体的なコード提案をコードブロックで記載している
- [ ] 既存コードのパターン・構成を確認し、同じパターンで実装している
- [ ] 変更範囲が必要最小限であること

### ビルド・テスト (ビルドシステムに変更がある場合)
- [ ] ビルドが成功する
- [ ] 既存テストが全件パスする
- [ ] 新規・変更機能に対するテストが存在する (なければ新規作成)

### iOS / SwiftUI (Swift コードに変更がある場合)
- [ ] シミュレータビルドが成功する (AGENTS.md「検証方法」の手順でログを検査する)
- [ ] ユニットテストが全件パスする (時刻依存ロジックは Date 注入でテストする)
- [ ] AlarmKit への登録は `AlarmKitScheduler.apply` の 1 経路を通っている (`.claude/rules/ios-alarmkit-constraints.md`)
- [ ] app と Extension の両方で使う型は `Alarmify/Shared/` に置き、両ターゲットに所属させている

### 動作確認 (UI・挙動に変更がある場合)
- [ ] AGENTS.md「検証方法」に従い、simtunnel を優先して動作確認する。ローカルへの切り替え条件と push の検証可能範囲も同節に従う
- [ ] UI 変更はスクリーンショットで描画を確認してから完了報告する

### 共通
- [ ] エラーメッセージはそのまま表示 (加工・プレフィックス除去なし)
