Signalarm は、外部サービスからの HTTP リクエストを iPhone の本物のアラームに変えるアプリです。

通知ではありません。iOS 26 の AlarmKit によるアラームなので、サイレントモードや集中モードの最中でも鳴り、ロック画面に大きく表示され、アプリを閉じていても動きます。

■ 使い方は 3 ステップ
・アプリでアラームの権限を許可し、API トークンを発行します
・GitHub Actions、Home Assistant、Grafana、Uptime Kuma、cron、Zapier、ショートカットなど、HTTP リクエストを送れるものから Signalarm の API を呼びます
・指定した日時に、あなたの iPhone で本物のアラームが鳴ります。アプリを開く必要はありません

■ こんな時に
・デプロイやバッチ処理の完了・失敗を、通知を見逃さずにアラームで受け取りたい
・監視ツールの重大アラートで、深夜でも確実に起こされたい
・ホームオートメーションのイベント (侵入検知、センサー) で iPhone を鳴らしたい
・サーバー側の予定表から、その日の起床アラームを自動で登録したい

■ API から
・アラームの登録、再スケジュール、取り消し
・タイトルを付けて、どのサービスからのアラームかを鳴った時に確認

■ プラン
・無料: API トークン 1 つと、毎月一定回数までのアラーム登録
・Pro: 複数のトークン、無制限のアラーム登録、アラーム履歴

■ プライバシー
・サーバーに保存するのは、配送に必要なアカウント識別子・デバイストークン・アラーム要求だけ。アラーム要求は 30 日で自動削除されます
・広告 SDK や分析 SDK は使っていません
