Signalarm 会把任何服务发出的 HTTP 请求转换为 iPhone 上的真实闹钟。

这不是通知。Signalarm 使用 iOS 26 的 AlarmKit，因此即使在静音模式和专注模式下，闹钟也会响起，并在锁定屏幕上醒目显示；即使应用已关闭，也能正常工作。

■ 三步即可
• 在应用中允许闹钟权限，并创建 API 令牌
• 从任何能发送 HTTP 请求的服务调用 Signalarm API：GitHub Actions、Home Assistant、Grafana、Uptime Kuma、cron、Zapier、快捷指令
• 到达你设置的时间后，iPhone 会响起真实闹钟。无需打开应用

■ 适用场景
• 将部署或批处理任务的结果作为不会错过的闹钟接收
• 在凌晨 3 点通过监控系统的严重告警可靠地叫醒你
• 通过家庭自动化事件（入侵、传感器）让手机响铃
• 根据服务器端日历安排明天的起床闹钟

■ 通过 API
• 安排、重新安排和取消闹钟
• 为每个闹钟设置标题，以便知道是哪个服务触发了它

■ 方案
• 免费版：1 个 API 令牌，每月可使用一定数量的闹钟
• Pro：多个令牌、无限闹钟、闹钟历史记录

■ 隐私
• 服务器只存储完成送达所需的信息：账户标识符、设备令牌和闹钟请求。闹钟请求会在 30 天后自动删除
• 不使用广告 SDK，不使用分析 SDK
