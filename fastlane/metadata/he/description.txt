Signalarm הופכת בקשת HTTP מכל שירות לאזעקה אמיתית ב-iPhone שלך.

לא התראה. Signalarm משתמשת ב-AlarmKit ב-iOS 26, ולכן האזעקה מצלצלת גם במצב שקט ובמצב ריכוז, ממלאת את מסך הנעילה ופועלת גם כשהאפליקציה סגורה.

■ שלושה שלבים
- אפשר לאזעקות באפליקציה וצור טוקן API
- קרא ל-API של Signalarm מכל דבר שיכול לשלוח בקשת HTTP: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, קיצורים
- בשעה שקבעת, ה-iPhone שלך יצלצל באזעקה אמיתית. לא תצטרך לפתוח את האפליקציה

■ מיועד ל
- קבלת תוצאת פריסה או משימת אצווה כאזעקה שאי אפשר לפספס
- התעוררות אמינה מהתראה קריטית ממערכת הניטור שלך ב-3 לפנות בוקר
- צלצול ב-iPhone שלך בעקבות אירועים של אוטומציה ביתית (חדירה, חיישנים)
- תזמון אזעקת ההשכמה למחר מלוח שנה בצד השרת

■ מה-API
- תזמן, תזמן מחדש ובטל אזעקות
- הוסף כותרת לכל אזעקה כדי לדעת איזה שירות הפעיל אותה

■ מסלולים
- חינם: טוקן API אחד ומכסה חודשית של אזעקות
- Pro: כמה טוקנים, אזעקות ללא הגבלה והיסטוריית אזעקות

■ פרטיות
- השרת שומר רק את מה שנדרש למסירה: מזהה חשבון, טוקנים של מכשירים ובקשות לאזעקות. בקשות לאזעקות נמחקות אוטומטית לאחר 30 ימים
- ללא SDK של פרסומות וללא SDK של ניתוח נתונים
