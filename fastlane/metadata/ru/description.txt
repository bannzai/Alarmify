Signalarm превращает HTTP-запрос от любого сервиса в настоящий будильник на вашем iPhone.

Это не уведомление. Signalarm использует AlarmKit в iOS 26, поэтому будильник звонит в бесшумном режиме и режиме фокусирования, отображается на весь экран блокировки и работает даже при закрытом приложении.

■ Три шага
- Разрешите будильники в приложении и создайте API-токен
- Вызовите API Signalarm из любого сервиса, который умеет отправлять HTTP-запросы: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, Команды
- В заданное вами время на iPhone прозвучит настоящий будильник. Открывать приложение не потребуется

■ Для чего подходит
- Получать результат деплоя или пакетной задачи в виде будильника, который невозможно пропустить
- Надёжно просыпаться от критического оповещения системы мониторинга в 3 часа ночи
- Включать звонок на телефоне по событиям домашней автоматизации (вторжение, датчики)
- Планировать утренний будильник на завтра из календаря на сервере

■ Из API
- Планировать, переносить и отменять будильники
- Указывать название каждого будильника, чтобы знать, какой сервис его запустил

■ Тарифы
- Бесплатный: один API-токен и ежемесячный лимит будильников
- Pro: несколько токенов, неограниченное число будильников, история будильников

■ Конфиденциальность
- На сервере хранится только необходимое для доставки: идентификатор аккаунта, токены устройств и запросы на будильники. Запросы на будильники автоматически удаляются через 30 дней
- Никаких SDK для рекламы и аналитики
