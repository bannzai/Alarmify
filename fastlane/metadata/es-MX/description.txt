Signalarm convierte una solicitud HTTP de cualquier servicio en una alarma real en tu iPhone.

No es una notificación. Signalarm usa AlarmKit en iOS 26, por lo que la alarma suena incluso en modo Silencio y con Concentración activada, ocupa la pantalla bloqueada y funciona aunque la app esté cerrada.

■ Tres pasos
- Permite las alarmas en la app y crea un token de API
- Llama a la API de Signalarm desde cualquier servicio que pueda enviar una solicitud HTTP: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, Atajos
- A la hora que establezcas, tu iPhone hará sonar una alarma real. No tienes que abrir la app

■ Ideal para
- Recibir como alarma el resultado de un despliegue o trabajo por lotes para no pasarlo por alto
- Despertarte de forma confiable a las 3 a. m. con una alerta crítica de tu monitoreo
- Hacer sonar tu teléfono a partir de eventos de automatización del hogar (intrusión, sensores)
- Programar la alarma para despertarte mañana desde un calendario del servidor

■ Desde la API
- Programar, reprogramar y cancelar alarmas
- Asignar un título a cada alarma para saber qué servicio la activó

■ Planes
- Gratis: un token de API y una cantidad mensual incluida de alarmas
- Pro: varios tokens, alarmas ilimitadas e historial de alarmas

■ Privacidad
- El servidor solo guarda lo necesario para la entrega: un identificador de cuenta, tokens de dispositivo y solicitudes de alarma. Las solicitudes de alarma se eliminan automáticamente después de 30 días
- Sin SDK de anuncios ni SDK de analítica
