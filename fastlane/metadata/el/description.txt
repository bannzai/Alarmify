Το Signalarm μετατρέπει ένα αίτημα HTTP από οποιαδήποτε υπηρεσία σε πραγματικό ξυπνητήρι στο iPhone σου.

Δεν είναι ειδοποίηση. Το Signalarm χρησιμοποιεί το AlarmKit στο iOS 26, έτσι το ξυπνητήρι χτυπά ακόμα και σε Αθόρυβη λειτουργία και σε Συγκέντρωση, καταλαμβάνει την οθόνη κλειδώματος και λειτουργεί ακόμα κι όταν η εφαρμογή είναι κλειστή.

■ Τρία βήματα
- Επίτρεψε τα ξυπνητήρια στην εφαρμογή και δημιούργησε ένα token API
- Κάλεσε το API του Signalarm από οτιδήποτε μπορεί να στείλει ένα αίτημα HTTP: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, Συντομεύσεις
- Την ώρα που ορίζεις, το iPhone σου χτυπά με πραγματικό ξυπνητήρι. Δεν χρειάζεται ποτέ να ανοίξεις την εφαρμογή

■ Ιδανικό για
- Να λαμβάνεις το αποτέλεσμα ενός deploy ή μιας μαζικής εργασίας ως ξυπνητήρι που δεν γίνεται να χάσεις
- Να σε ξυπνά αξιόπιστα μια κρίσιμη ειδοποίηση από την παρακολούθησή σου στις 3 π.μ.
- Να χτυπά το τηλέφωνό σου από συμβάντα οικιακού αυτοματισμού (παραβίαση, αισθητήρες)
- Να προγραμματίζεις το αυριανό ξυπνητήρι από ένα ημερολόγιο στον διακομιστή

■ Από το API
- Προγραμμάτισε, επαναπρογραμμάτισε και ακύρωσε ξυπνητήρια
- Δώσε σε κάθε ξυπνητήρι έναν τίτλο, ώστε να γνωρίζεις ποια υπηρεσία το ενεργοποίησε

■ Προγράμματα
- Δωρεάν: ένα token API και μηνιαίο όριο ξυπνητηριών
- Pro: πολλαπλά token, απεριόριστα ξυπνητήρια, ιστορικό ξυπνητηριών

■ Απόρρητο
- Ο διακομιστής αποθηκεύει μόνο όσα χρειάζονται για την παράδοση: ένα αναγνωριστικό λογαριασμού, διακριτικά συσκευών και αιτήματα ξυπνητηριών. Τα αιτήματα ξυπνητηριών διαγράφονται αυτόματα μετά από 30 ημέρες
- Δεν χρησιμοποιούνται SDK διαφημίσεων ούτε SDK αναλυτικών στοιχείων
