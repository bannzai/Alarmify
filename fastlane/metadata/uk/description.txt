Signalarm перетворює HTTP-запит від будь-якого сервісу на справжній будильник на вашому iPhone.

Це не сповіщення. Signalarm використовує AlarmKit в iOS 26, тому будильник лунає навіть у режимах «Без звуку» та «Фокусування», займає весь екран блокування й працює, навіть коли застосунок закрито.

■ Три кроки
- Дозвольте застосунку використовувати будильники й створіть API-токен
- Викликайте API Signalarm із будь-чого, що може надсилати HTTP-запити: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, Команди
- У встановлений вами час на вашому iPhone пролунає справжній будильник. Відкривати застосунок не потрібно

■ Для таких завдань
- Отримувати результат розгортання чи пакетного завдання як будильник, який ви не пропустите
- Надійно прокидатися о 3-й ночі завдяки критичному сповіщенню від системи моніторингу
- Вмикати будильник на телефоні за подіями домашньої автоматизації (проникнення, датчики)
- Планувати завтрашній будильник для пробудження з календаря на сервері

■ Через API
- Плануйте, переплановуйте та скасовуйте будильники
- Додавайте назву до кожного будильника, щоб знати, який сервіс його активував

■ Тарифні плани
- Безкоштовний: один API-токен і щомісячний ліміт будильників
- Pro: кілька токенів, необмежена кількість будильників, історія будильників

■ Конфіденційність
- Сервер зберігає лише дані, потрібні для доставки: ідентифікатор облікового запису, токени пристроїв і запити на будильники. Запити на будильники автоматично видаляються через 30 днів
- Без SDK для реклами та аналітики
