Signalarm은 모든 서비스의 HTTP 요청을 iPhone의 실제 알람으로 바꿔줘요.

알림이 아니에요. Signalarm은 iOS 26의 AlarmKit을 사용해 무음 모드와 집중 모드에서도 알람이 울리고, 잠금 화면을 가득 채워 표시되며, 앱이 닫혀 있어도 작동해요.

■ 3단계로 간단하게
- 앱에서 알람을 허용하고 API 토큰을 만들어요
- HTTP 요청을 보낼 수 있는 곳에서 Signalarm API를 호출해요: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, 단축어
- 설정한 시간이 되면 iPhone에서 실제 알람이 울려요. 앱을 열 필요가 없어요

■ 이런 용도로 사용해요
- 놓치고 싶지 않은 배포 또는 배치 작업 결과를 알람으로 받아요
- 모니터링의 중요한 알림으로 3 a.m.에도 확실히 깨요
- 홈 오토메이션 이벤트(침입,센서)로 휴대폰을 울려요
- 서버 측 캘린더에서 내일 기상 알람을 예약해요

■ API로 할 수 있어요
- 알람을 예약하고, 다시 예약하고, 취소해요
- 각 알람에 제목을 지정해 어떤 서비스가 실행했는지 알 수 있어요

■ 요금제
- 무료: API 토큰 1개와 매월 제공되는 알람 사용량
- Pro: 여러 토큰, 무제한 알람, 알람 기록

■ 개인정보 보호
- 서버에는 전송에 필요한 정보만 저장해요: 계정 식별자, 기기 토큰, 알람 요청. 알람 요청은 30일 후 자동 삭제돼요
- 광고 SDK와 분석 SDK를 사용하지 않아요
