Signalarm เปลี่ยน HTTP request จากบริการใดก็ได้ให้เป็นการปลุกจริงบน iPhone ของคุณ

ไม่ใช่การแจ้งเตือน Signalarm ใช้ AlarmKit บน iOS 26 จึงปลุกผ่านโหมดเงียบและโฟกัส แสดงเต็มหน้าจอล็อก และทำงานได้แม้ปิดแอปอยู่

■ สามขั้นตอน
- อนุญาตการปลุกในแอปและสร้างโทเค็น API
- เรียกใช้ Signalarm API จากอะไรก็ตามที่ส่ง HTTP request ได้ เช่น GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier และคำสั่งลัด
- เมื่อถึงเวลาที่ตั้งไว้ iPhone จะปลุกจริง โดยไม่ต้องเปิดแอป

■ เหมาะสำหรับ
- รับผลการ deploy หรืองานแบตช์เป็นเสียงปลุกที่พลาดไม่ได้
- ตื่นอย่างมั่นใจจากการแจ้งเตือนสำคัญของระบบมอนิเตอร์ตอน 3 a.m.
- ให้โทรศัพท์ปลุกจากเหตุการณ์ของระบบบ้านอัตโนมัติ (การบุกรุก เซ็นเซอร์)
- ตั้งเวลาปลุกสำหรับวันพรุ่งนี้จากปฏิทินบนเซิร์ฟเวอร์

■ จาก API
- ตั้งเวลา เลื่อนเวลา และยกเลิกการปลุก
- ตั้งชื่อให้การปลุกแต่ละครั้ง เพื่อให้ทราบว่าบริการใดเป็นผู้เรียกใช้

■ แผนบริการ
- ฟรี: โทเค็น API 1 รายการ และโควตาการปลุกต่อเดือน
- Pro: โทเค็นหลายรายการ การปลุกไม่จำกัด และประวัติการปลุก

■ ความเป็นส่วนตัว
- เซิร์ฟเวอร์จัดเก็บเฉพาะข้อมูลที่จำเป็นต่อการส่ง ได้แก่ ตัวระบุบัญชี โทเค็นอุปกรณ์ และคำขอปลุก คำขอปลุกจะถูกลบโดยอัตโนมัติหลัง 30 วัน
- ไม่มีโฆษณา SDK และไม่มีการวิเคราะห์ SDK
