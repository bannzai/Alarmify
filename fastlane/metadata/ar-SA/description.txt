Signalarm يحوّل طلب HTTP من أي خدمة إلى منبّه حقيقي على iPhone.

ليس إشعارًا. يستخدم Signalarm AlarmKit في iOS 26، لذلك يرن المنبّه حتى في الوضع الصامت وأثناء التركيز، ويظهر بوضوح على شاشة القفل، ويعمل حتى عندما يكون التطبيق مغلقًا.

■ ثلاث خطوات
- امنح التطبيق إذن المنبّهات وأنشئ رمز API
- استدعِ API الخاص بـ Signalarm من أي شيء يمكنه إرسال طلب HTTP: GitHub Actions، Home Assistant، Grafana، Uptime Kuma، cron، Zapier، الاختصارات
- في الوقت الذي تحدده، يرن iPhone بمنبّه حقيقي. لا تحتاج إلى فتح التطبيق مطلقًا

■ صُمّم من أجل
- الحصول على نتيجة النشر أو المهمة الدفعية كمنبّه لا يفوتك
- الاستيقاظ بشكل موثوق على تنبيه حرج من نظام المراقبة لديك في الساعة 3 صباحًا
- جعل هاتفك يرن عند وقوع أحداث الأتمتة المنزلية (التسلل، المستشعرات)
- جدولة منبّه استيقاظ الغد من تقويم على الخادم

■ من API
- جدولة المنبّهات وإعادة جدولتها وإلغاؤها
- امنح كل منبّه عنوانًا لتعرف أي خدمة أطلقته

■ الخطط
- مجاني: رمز API واحد وحصة شهرية من المنبّهات
- Pro: رموز متعددة، منبّهات غير محدودة، وسجل المنبّهات

■ الخصوصية
- لا يخزّن الخادم سوى ما يلزم للتسليم: معرّف الحساب، ورموز الأجهزة، وطلبات المنبّهات. تُحذف طلبات المنبّهات تلقائيًا بعد 30 يومًا
- لا نستخدم SDK للإعلانات أو SDK للتحليلات
