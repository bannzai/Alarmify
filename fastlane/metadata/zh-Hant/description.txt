Signalarm 會把任何服務發出的 HTTP 請求，轉換成 iPhone 上的真正鬧鐘。

這不是通知。Signalarm 使用 iOS 26 的 AlarmKit，因此即使開啟靜音模式或專注模式，鬧鐘仍會響起、佔滿鎖定畫面，而且即使 App 已關閉也能運作。

■ 三個步驟
- 在 App 中允許鬧鐘權限，並建立 API token
- 從任何能傳送 HTTP 請求的服務呼叫 Signalarm API：GitHub Actions、Home Assistant、Grafana、Uptime Kuma、cron、Zapier、捷徑
- 到達你設定的時間時，iPhone 會響起真正的鬧鐘。完全不需要開啟 App

■ 適合用於
- 用不容錯過的鬧鐘接收部署或批次工作的結果
- 在凌晨 3 點，讓監控工具的重大警示可靠地喚醒你
- 透過家庭自動化事件（入侵、感測器）讓手機響起
- 從伺服器端行事曆排程明天的起床鬧鐘

■ 透過 API
- 排程、重新排程及取消鬧鐘
- 為每個鬧鐘加上標題，方便確認是哪個服務觸發

■ 方案
- 免費：一組 API token，以及每月固定數量的鬧鐘額度
- Pro：多組 token、無限鬧鐘及鬧鐘記錄

■ 隱私權
- 伺服器只儲存傳送所需的資料：帳戶識別碼、裝置 token 及鬧鐘請求。鬧鐘請求會在 30 天後自動刪除
- 不使用廣告 SDK，也不使用分析 SDK
