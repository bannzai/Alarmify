Signalarm किसी भी सेवा से आने वाले HTTP अनुरोध को आपके iPhone पर असली अलार्म में बदल देता है।

यह नोटिफिकेशन नहीं है। Signalarm iOS 26 पर AlarmKit का इस्तेमाल करता है, इसलिए अलार्म साइलेंट मोड और फ़ोकस के दौरान भी बजता है, लॉक स्क्रीन पर प्रमुखता से दिखाई देता है और ऐप बंद होने पर भी काम करता है।

■ तीन चरण
• ऐप में अलार्म की अनुमति दें और API टोकन बनाएँ
• HTTP अनुरोध भेजने वाली किसी भी सेवा से Signalarm API को कॉल करें: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, शॉर्टकट्स
• आपके द्वारा तय किए गए समय पर आपके iPhone पर असली अलार्म बजेगा। आपको ऐप खोलने की ज़रूरत नहीं पड़ेगी

■ इनके लिए उपयोगी
• डिप्लॉय या बैच जॉब के नतीजे का ऐसा अलार्म पाना जिसे आप मिस न कर सकें
• रात 3 बजे मॉनिटरिंग के महत्वपूर्ण अलर्ट से भरोसेमंद तरीके से जागना
• होम ऑटोमेशन इवेंट (घुसपैठ, सेंसर) से आपका फ़ोन बजाना
• सर्वर-साइड कैलेंडर से अगले दिन का वेक-अप अलार्म शेड्यूल करना

■ API से
• अलार्म शेड्यूल, फिर से शेड्यूल और रद्द करें
• हर अलार्म को शीर्षक दें, ताकि आपको पता चल सके कि उसे किस सेवा ने ट्रिगर किया

■ प्लान
• मुफ़्त: एक API टोकन और हर महीने निर्धारित संख्या तक अलार्म
• Pro: कई टोकन, असीमित अलार्म और अलार्म इतिहास

■ गोपनीयता
• सर्वर पर केवल डिलीवरी के लिए आवश्यक जानकारी संग्रहीत होती है: अकाउंट पहचानकर्ता, डिवाइस टोकन और अलार्म अनुरोध। अलार्म अनुरोध 30 दिनों के बाद अपने-आप हटा दिए जाते हैं
• कोई विज्ञापन SDK या एनालिटिक्स SDK नहीं
