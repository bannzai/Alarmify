Alarmify turns an HTTP request from any service into a real alarm on your iPhone.

Not a notification. Alarmify uses AlarmKit on iOS 26, so the alarm rings through Silent mode and Focus, fills the lock screen, and works even when the app is closed.

■ Three steps
- Allow alarms in the app and create an API token
- Call the Alarmify API from anything that can send an HTTP request: GitHub Actions, Home Assistant, Grafana, Uptime Kuma, cron, Zapier, Shortcuts
- At the time you set, your iPhone rings a real alarm. You never have to open the app

■ Made for
- Getting a deploy or batch job result as an alarm you cannot miss
- Being reliably woken up by a critical alert from your monitoring at 3 a.m.
- Ringing your phone from home automation events (intrusion, sensors)
- Scheduling tomorrow's wake-up from a server-side calendar

■ From the API
- Schedule, reschedule, and cancel alarms
- Give each alarm a title so you know which service fired it

■ Plans
- Free: one API token and a monthly allowance of alarms
- Pro: multiple tokens, unlimited alarms, alarm history

■ Privacy
- The server stores only what delivery needs: an account identifier, device tokens, and alarm requests. Alarm requests are deleted automatically after 30 days
- No ads SDK, no analytics SDK
