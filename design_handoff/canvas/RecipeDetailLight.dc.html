Steps
1Store the token as the repository secret ALARMIFY_TOKEN. The gh CLI prompts for the value so it stays out of your shell history
2Add the step at the end of the job. if: always() also rings after a failure
Workflow step
- name: Ring my iPhone if: always() env: ALARMIFY_TOKEN: ${{ secrets.ALARMIFY_TOKEN }} WORKFLOW: ${{ github.workflow }} STATUS: ${{ job.status }} run: | curl -sS --fail-with-body -X POST \ https://api.alarmify.app/v1/alarms \ -H "Authorization: Bearer $ALARMIFY_TOKEN" \ -H "Content-Type: application/json" \ -d "$(jq -cn --arg title \ "$WORKFLOW: $STATUS" \ '{fire_in: 0, title: $title}')"
