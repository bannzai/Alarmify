Webhook to real iPhone alarm

Any HTTP request can wake you up.

Alarmify gives you an HTTPS endpoint and a personal token. Call it from CI, a monitor, your smart home, or a shell script, and a real alarm is scheduled on your iPhone. Not a push notification you can sleep through.

Schedule an alarm Planned API (予定) 
curl -X POST https://api.alarmify.app/v1/alarms \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"fire_at":"2026-09-03T07:00:00Z","title":"Deploy finished"}'

The API is still under development. The endpoint, the request shape and the host name above show the planned interface and may change before release.

How it works

Three steps, then forget about it.

01

Get a token in the app

Install Alarmify and issue a personal bearer token from the app. The token belongs to your account and to your iPhone.

02

Call the API from anything

Any system that can send an HTTPS request can schedule an alarm: a workflow step, a monitoring rule, a cron job, a shortcut.

03

Your iPhone rings

At the requested time a real alarm goes off on your device, with the title you sent, so you know what woke you before you open anything.

Why a real alarm

A notification is a suggestion. An alarm is not.

Alarmify schedules a system alarm through AlarmKit, the same mechanism the built-in Clock app uses. That is what makes it survive the settings that silence everything else.

Rings in Silent mode

The ring switch does not mute it. Your phone can stay silent all evening and still wake you at 3am.

Breaks through Focus

Sleep Focus and Do Not Disturb hold back notifications. An alarm still sounds.

Shows on the lock screen

The alarm appears with its title, so an incident has a name before you unlock anything.

Works when the app is closed

Once scheduled, the alarm lives in the system. Alarmify does not have to be running.

Built on AlarmKit

Uses Apple's alarm framework rather than a background push, so it behaves like a real alarm and not like a message.

iOS 26 and later

AlarmKit requires iOS 26, so Alarmify targets iOS 26 and later on iPhone.

Integrations

Works with anything that can send an HTTP request.

There is nothing to install on the other side. If it can make a POST request with a header, it can wake you up.
